# 报销额度标准（示例数据）

> 这是一份**示例**附带文件，用来演示 skill 可以携带参考资料。
> 实际部署时应当替换成本组织真实的标准，或者删掉这份、改从知识库检索。

## 住宿（每晚上限，人民币）

| 城市等级 | 上限 | 说明 |
|---|---|---|
| 一线 | 600 | 北京、上海、广州、深圳 |
| 二线 | 450 | 省会城市与计划单列市 |
| 其他 | 350 | |

## 市内交通

据实报销，单日上限 100 元。需要提供行程凭证（打车软件行程单或出租车发票）。

## 餐饮

每人每日上限 120 元。跨越用餐时段的当日往返出差按实际时段折算。

## 报销时限

费用发生后 **30 个自然日**内提交。超期需在申请里写明理由，由上级签批后走例外流程。

## 需要发票的情形

单笔 100 元以上一律需要发票。100 元以下可用收款凭证替代，但同一次出差累计不得
超过 300 元。
