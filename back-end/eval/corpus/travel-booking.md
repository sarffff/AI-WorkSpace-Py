# 差旅预订指引

## 适用范围

本指引说明**怎么订**；能报多少见《费用报销制度》的差旅标准一节。
两份文件冲突时以《费用报销制度》为准。

## 预订渠道

机票与高铁票须通过公司差旅平台预订，个人自行购买的不保证可报销。
平台不支持的境外线路，可由行政代订。

## 提前期

国内行程须在出发前 **5 个工作日**提交申请。
紧急行程（3 个工作日以内）需部门负责人在系统内特批。
境外行程须提前 15 个工作日，因涉及签证与保险。

## 舱位与席别

| 行程类型 | 默认标准 |
| -------- | -------- |
| 城际高铁 | 二等座 |
| 国内航班 | 经济舱 |
| 境外航班（6 小时以内） | 经济舱 |
| 境外航班（超过 6 小时） | 超级经济舱 |

职级 P8 及以上国内航班可升舱至超级经济舱。
飞行距离超过 1200 公里方可购机票，否则默认高铁。

## 住宿预订

住宿须通过平台协议酒店预订，超出协议价的部分自理。
同城两人以上出差原则上安排合住标准间，特殊情况需说明。

## 变更与退订

因公变更产生的手续费凭说明可报；个人原因产生的手续费自理。
无故未登机（no-show）产生的全额损失由个人承担。

## 保险

境内行程由公司统一投保意外险，无需个人操作。
境外行程须在平台勾选境外医疗险，未勾选的行程不予审批。
