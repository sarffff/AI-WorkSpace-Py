# 绩效管理办法

## 周期

绩效周期为半年，考核月为 6 月与 12 月。
入职未满 3 个月的不参与当期考核；试用期考核见《员工手册》。

## 等级与分布

| 等级 | 含义 | 参考比例 |
| ---- | ---- | -------- |
| S | 远超预期 | 5% |
| A | 超出预期 | 20% |
| B | 符合预期 | 60% |
| C | 部分达成 | 10% |
| D | 未达预期 | 5% |

比例为参考值，团队少于 8 人时不做强制分布。

## 流程

自评 → 主管评 → 跨部门校准会 → 结果沟通。
校准会由 HRBP 主持，主管须提供事实依据，不接受仅凭印象的评级。
结果沟通须一对一进行并留有书面记录。

## 申诉

对结果有异议的，可在结果沟通后 **10 个工作日**内向 HRBP 提交书面申诉。
申诉由 HRBP 与被申诉主管的上一级共同复核，复核结论为最终结论。
申诉期间不影响调薪与奖金发放的正常流程。

## 与调薪的关系

调薪窗口每年一次，在 12 月考核结束后统一执行。
连续两期 C 的员工不参与调薪；出现 D 的进入绩效改进计划（PIP）。

## 绩效改进计划

PIP 周期为 **3 个月**，由主管与 HRBP 共同制定并明确可衡量目标。
PIP 期满未达标的，公司可依法解除劳动合同。
PIP 期间不得申请内部转岗。
