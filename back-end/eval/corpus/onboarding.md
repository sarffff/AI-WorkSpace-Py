# 新人入职指南

## 第一天

1. 到 1 楼前台领取工牌与门禁卡
2. 登录 `https://sso.internal.acme.dev` 完成账号激活并绑定 MFA
3. 在 IT 服务台工单系统提交开发机申领

工牌遗失需在 IT 服务台挂失，补办工本费 50 元。

## 账号开通时效

| 系统 | 时效 |
| ---- | ---- |
| SSO / 邮箱 | 入职当天 |
| 代码仓库 | 1 个工作日 |
| 数据平台（只读） | 2 个工作日 |
| 生产环境跳板机 | 需部门负责人审批，通常 3 个工作日 |

## 开发环境

统一使用 Python 3.11 与 Node.js 20 LTS。
依赖通过内网镜像安装：

```
pip config set global.index-url https://mirror.internal.acme.dev/pypi/simple
npm config set registry https://mirror.internal.acme.dev/npm/
```

本地起服务默认端口段为 3000 至 3999，避免与内网服务冲突。

## 导师制

每位新人配一名导师，导师制周期为入职后 **3 个月**。
导师每周至少安排一次 1:1，并在第 30、60、90 天各提交一次评估。

新人在导师制期间的代码合并需导师作为第二审阅人。

## 培训

入职两周内需完成三门必修课：信息安全意识、合规与反舞弊、研发流程规范。
未按期完成的，账号权限将暂时降级为只读，直至补齐。

必修课在学习平台 `https://learn.internal.acme.dev` 上完成，每门约 40 分钟。

## 常见问题

**VPN 连不上？** 先确认 MFA 时间同步，再检查是否用了个人热点（部分运营商 UDP 被封）。

**收不到邮件？** 新邮箱首日可能有 2 小时同步延迟，超过请提工单。
