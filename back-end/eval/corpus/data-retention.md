# 数据留存与销毁规范

## 适用范围

本规范规定各类数据**保留多久、怎么销毁**。
数据如何分级、谁能访问见《信息安全规范》，两者配套使用。

## 留存期限

| 数据类型 | 留存期 | 到期动作 |
| -------- | ------ | -------- |
| 应用运行日志 | 90 天 | 自动删除 |
| 访问审计日志 | 3 年 | 归档冷存 |
| 财务凭证 | 10 年 | 归档冷存 |
| 劳动合同 | 离职后 2 年 | 归档冷存 |
| 客户业务数据 | 合同终止后 6 个月 | 删除并出具证明 |
| 面试记录 | 12 个月 | 自动删除 |

归档冷存的数据默认不可直接查询，需走审批调取。

## 备份

生产数据每日增量、每周全量备份，备份保留 **35 天**。
备份恢复演练每季度一次，未通过演练的备份策略视为无效。

## 销毁

电子数据销毁须不可恢复，仅移入回收站不算销毁。
物理介质（硬盘、U 盘）须物理粉碎并留存销毁记录。
销毁须双人在场并签字，记录保留 3 年。

## 删除请求

客户提出删除请求的，须在 **30 日**内完成并书面回复。
因法定义务须继续保留的部分，须在回复中说明依据与范围。

## 例外

进入法律诉讼或监管调查的数据，留存期自动延长至程序结束，期间禁止任何销毁操作。
触发该例外须由法务在系统内挂起对应的自动删除任务。
