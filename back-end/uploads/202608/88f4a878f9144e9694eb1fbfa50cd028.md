# 信息安全规范

## 账号与口令

口令长度不少于 14 位，且须包含大小写字母、数字、符号中的至少三类。
禁止在多个系统间复用口令。

生产环境账号强制开启 MFA。口令有效期 **180 天**，到期前 14 天开始提醒。
连续 5 次认证失败锁定账号 30 分钟。

## 数据分级

| 等级 | 说明 | 存储要求 |
| ---- | ---- | -------- |
| L1 公开 | 官网、公开文档 | 无特殊要求 |
| L2 内部 | 流程文档、会议记录 | 仅限内网访问 |
| L3 机密 | 客户名单、合同、财务数据 | 静态加密 + 访问审计 |
| L4 绝密 | 密钥、生产数据库凭据 | 密钥管理系统托管，禁止落盘 |

L3 及以上数据禁止上传至任何第三方 SaaS，包括在线文档与 AI 对话工具。

## 生产环境访问

生产环境访问遵循最小权限原则，默认只读。
写权限需通过《临时提权申请》获取，单次有效期最长 **4 小时**，到期自动回收。

所有生产操作经过跳板机并全程录屏，录像保留 180 天。

## 密钥管理

密钥一律由 KMS 托管，代码与配置文件中不得出现明文密钥。
CI 通过 OIDC 短期凭据获取权限，禁止配置长期 AccessKey。

发现密钥泄露应在 **1 小时内**完成吊销并轮换，同时提交安全事件报告。

## 终端安全

办公终端必须开启全盘加密与自动锁屏（空闲 5 分钟）。
禁止关闭 EDR 客户端。外接存储设备需事先登记。

## 安全事件响应

发现疑似安全事件立即通知 security@acme.dev 并保留现场，不要自行重启或清理日志。
P0 级事件（涉及 L4 数据或生产可用性）需在 15 分钟内拉起应急群。
